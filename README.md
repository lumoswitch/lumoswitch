### 🔎 DeployChecker

A Python CLI for automated **post-deployment verification**.

Instead of manually checking services, containers, versions, and logs after a deployment, DeployChecker runs the checks from a simple YAML configuration.

**Current checks include:**

* 🌐 HTTP health checks
* 🐳 Docker container status
* 📋 Log pattern detection
* 🏷️ Application version verification
* ⚙️ YAML-based configuration
* 🧪 Automated tests
* 🔄 GitHub Actions CI

```bash
deploycheck verify config.yml
```

Built with **Python, Typer, Rich, Pydantic, HTTPX, Docker SDK and PyYAML**.

👉 [View DeployChecker](https://github.com/lumoswitch/DeployChecker)
